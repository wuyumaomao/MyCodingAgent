# CodePilot 本地代码助手

**项目介绍：** 面向代码仓库中的长链路开发任务，独立设计并实现本地 Agent Runtime 原型，覆盖模型接入、工具调用、上下文管理、记忆存储、运行审计与任务评测，探索如何让代码 Agent 在可控边界内持续完成任务。

**技术栈：** Python 、Agent Harness 、Tool Calling、JSON Schema、Context Engineering、Layered Memory 

## 核心职责与项目成果

- **Agent Runtime 框架：** 负责整体架构与核心流程开发，统一模型接入、多个工具执行、会话状态管理和checkpoints恢复流程，实现感知、决策、行动、记录的闭环。支持交互式运行模式，形成可复盘执行链路。

- **上下文治理：** 设计分层上下文管理和动态裁剪机制，通过对话历史按预算裁剪，工具结果分级生成摘要，工作记忆提炼，在保证上下文的完整性前提下，有效控制 prompt 长度。在12组长任务中，平均 prompt 长度由 6,964 降至 5,418，压缩约 22.2%，最高约 35.6%。

- **结构化记忆系统：** 为针对agent反复读取同一个文件，重复确认一个已知事实的问题，将任务摘要，文件摘要做了分层，结合freshness校验召回相关记忆。显著减少文件重复读取，提高整体效率。

- **工具安全：** 构建严工具调用的标准化与安全边界，为工具调用增加参数 Schema 校验、仓库路径边界、命令白名单、高风险审批和重复调用拦截。在测试场景中，结构化记录了多次路径逃逸，不合法参数拒绝。

- **评测与审计：** 建立包含 8 类固定任务的 Benchmark，先 Fake LLM 验证参数错误、路径越界、文件创建和修改等链路，并支持真实模型评测，每次运行生成 trace/report，落盘运行工件，以便问题审查和复盘。
